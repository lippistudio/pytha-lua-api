Waveboards

The Waveboards plugin generates parametric wave-shaped 3D surfaces on a rectangular base — suitable for corrugated boards, washboards, decorative panels, and any product with a profiled ripple surface. Multiple independent wave features can be layered and combined. All changes are previewed live in the 3D view.

Quick Start

  1. Set Name, Origin, and Dimensions.
  2. Choose a Base shape (One sided block or Two sided block).
  3. Select an Output mode (Face, Profile, or Solid).
  4. In the Features section, adjust the wave parameters of the default feature or add new ones with New.
  5. Confirm with OK to place the geometry.

Output Mode

ModeDescription
FaceCreates open surface polygons — one cross-section polygon per slice. Lightweight; suitable for visualisation or CNC toolpaths.
ProfileExtrudes each cross-section polygon by Profile thickness to produce a board-like solid profile along the length.
SolidTriangulates the surface into a fully closed solid body. All faces are included and merged into a single part.

Profile thickness is only active in Profile mode and defines the extrusion depth in object units (e.g. mm).

Features

A feature is a single wave component. Multiple features can be stacked — their displacements are summed at every surface point. Each feature has its own profile shape, direction, amplitude, and spatial envelope.

Use New to add a feature (it inherits the current feature's settings) and Delete to remove the selected feature.

Determines the cross-sectional shape of one wave cycle:

Each profile is also available as a (periodic) variant — the pattern tiles continuously rather than fading to zero outside the wave width.

Path Mode

ModeDescription
GlobalThe wave runs uniformly across the entire surface with constant amplitude.
PacketThe wave is localised in a band. A Gaussian envelope attenuates amplitude away from the centre in both U and V directions. Position with Center U/V, size with Size U/V.
DropRadial Gaussian centred on one point. Fades in all directions. Angle, Frequency, and Phase have no effect in this mode.

Combining Features

Each feature's displacement is computed independently and added to the surface. Examples:

  • A primary Global wave for the main corrugation + a second feature at higher frequency for fine texture.
  • Two Global features at different angles to produce a cross-hatch or diamond pattern.
  • A Packet feature that adds a localised raised band in the centre of the board.
  • A Drop feature to create a dimple or boss at a specific point.

Editing an Existing Shape

Waveboards stores all parameters with the created geometry. To edit a previously created wave shape, select the element in PYTHA and run Waveboards again via the plugin menu — the dialog will re-open with the original parameters loaded.

Tips

Resolution: Start with low Sections (20–30) and Points / section (32–48) while exploring, then increase for the final result.
Units: Amplitude is in the same units as Length/Width/Height (typically mm). All other wave parameters are in percent of the surface extent.
Periodic profiles: Use (periodic) variants with a Width (%) that divides 100 evenly (e.g. 10, 20, 25) for seamless repeating patterns.
Phase alignment: When stacking two Global features at the same angle, use Phase (%) to control the relative offset between them (50 = half-cycle shift).
